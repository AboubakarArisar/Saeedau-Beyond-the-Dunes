## Adding cleared audio

Encode an authorized original to a web-friendly MP3 or Ogg and save it in `public/audio/thar-radio/`. Add an entry to the JSON array in `manifest.json` with `title`, `artist`, and `file` fields. Use a filename such as `artist-song.mp3` for `file`. Keep the source and grant reference with the asset records and follow any credit requirements.

Thar Soundtrack reads only the manifest and local audio files served with the game. The browser verification supplies generated test audio during the test run.
